# 콜센터 AX 워크벤치 — 전체 구현 기능 정리

**라이브**: https://callcenter-ax.pages.dev · **코드**: https://github.com/k95691368-ship-it/callcenter-ax
콜센터 현장의 업무 흐름 — *"STT, LLM, NLP, RAG 기술을 활용한 녹취 기반 분류·요약·검색,
VOC·의도 분석, 상담 품질 평가 자동화(Auto QA)"* — 를 동작하는 화면으로 구현했다.

## 원클릭 파이프라인 `/pipeline`
버튼 하나로 실제 프로덕션 API 6단계가 연속 실행된다:
**내장 음성 → ① Whisper STT → ② 도메인 용어 보정(튜닝 1단계) → ③ 화자 분리(NLP) →
④ LLM 통화 분석 → ⑤ Auto QA → ⑥ VOC 누적**. 시연용 가짜 경로 없음.
**🎙 내 목소리로 실행**: 그 자리에서 마이크 녹음을 멈추면 같은 6단계를 내 목소리가
통과한다 (미리듣기 제공, 서버 미보관).

## 1. 녹취 전사 `/stt` — 오픈소스 Whisper STT
- **Whisper large-v3-turbo**(Workers AI)로 한국어 전사 — API 키 없이 라이브
- **장시간 녹취 자동 분할 전사**: 4MB 초과 파일은 브라우저에서 16kHz 리샘플·55초 청크로
  분할해 순차 전사 (최대 약 27분) — 단발 호출 한계 돌파
- 입력 3종: 내장 샘플 원클릭 / **브라우저 마이크 녹음**(MediaRecorder) / 파일 업로드(≤6MB)
- **CER(문자 오류율) 측정**: 정답 스크립트 대비 Levenshtein 기반 정량 평가
- **Whisper 2종 모델 비교**: turbo vs base를 같은 음성으로 전사해 CER·지연 비교표
  (실측: turbo "한비텔레콤" 1자 오차 vs base "한 밑에 내 콤" 붕괴)
- **도메인 용어 보정(튜닝 1단계)**: 콜센터 용어 사전 후보정 + 보정 전/후 CER 개선 폭 표시
- **화자 분리**: 통짜 전사를 LLM이 상담사:/고객: 태깅 (원문 단어 보존) → QA 정확도 연결
- 텍스트 직접 입력 모드, 분석으로 보내기 연결. 업로드 음성 미보관

## 2. 통화 분석 `/analyze` — LLM 분류·요약·의도
- 유형 분류(가입/해지/요금/불만/기타) · 3줄 요약 · 감정(긍정~강성)+근거 · 의도 키워드 ·
  후속 조치 제안
- **에스컬레이션 원칙**: 법적 클레임·강성 민원·보상 요구는 AI가 결론 내리지 않고 담당자에게
  올림 — "반복은 대체하고 판단은 남긴다"
- **일괄 분석**: 통화 최대 5건을 LLM 호출 1회로 함께 구조화 → 건별 표 + VOC 일괄 누적
- 분석할 때마다 VOC 대시보드에 실시간 누적(localStorage, 서버 미전송)

## 3. 상담 품질 평가 `/qa` — Auto QA 이중 구조 100점
- **1층 규칙(결정적, 40점)**: 필수 멘트 5종 체크리스트 + 금지 표현 스캐너(위치 발췌·감점)
  — 화자 구분 시 상담사 발화만 평가. 키 없이도 실제 동작
- **2층 LLM(60점)**: 공감·명확성·해결력 각 20점 — **행동 앵커 루브릭**(구간별 구체 기준)과
  **일관성 밴드**(규칙 신호 기반 기대 구간 보정)로 실행 간 점수 편차를 구조적으로 축소
- **커스텀 체크리스트**: 콜센터별 필수 멘트를 직접 추가(최대 3개, 라벨+감지 키워드) —
  규칙 40점이 내장 5개+커스텀에 균등 재배분되어 만점 유지. 프론트·서버가 같은
  규칙 모듈을 공유해 기준 불일치가 원천적으로 없음
- 순수 함수 점수 계산(테스트 완비), SVG 게이지 + A~D 등급, 점수표 복사(코칭 공유용)

## 4. VOC 대시보드 `/voc`
- 내장 10건 + 직접 분석 건 합산: 유형 막대·감정 램프·일별 추이(경량 SVG)
- 통계 타일, 에스컬레이션 대기 목록, 통화 원장 테이블
- **AI 인사이트 리포트**: 집계 수치 + 에스컬레이션 통화 제목(개인정보 마스킹 후 최대 6건)을 LLM에 전달(통화 전문 미전송) → 핵심 발견·권고 액션 생성

## 5. RAG 지식 검색 `/search`
- **Vectorize 사전 인덱스**(벡터 DB): 질의 1건만 임베딩해 사전 색인 조회 — 코퍼스가
  수백 건이어도 검색 비용 동일. 콜드스타트 자가 시딩 + 실시간 임베딩 폴백
- **하이브리드 검색**: 벡터 유사도와 키워드 랭킹을 **RRF(k=60)**로 융합 — 의미 유사(벡터 강점)와 정확 용어 일치(키워드 강점)를 동시에
  잡는 실전 IR 설계. LLM은 근거 문단만 사용해 답변(인용 id 표시)
- **내 문서 실시간 인덱싱**: 사용자가 규정을 붙여넣으면(최대 5건) 즉시 임베딩되어 내장
  8건과 같은 코퍼스에서 검색 — 서버 미저장, "내 문서" 배지
- 폴백: 임베딩 불가 시 키워드 랭킹 → LLM 불가 시 발췌 답변

## 6. 실시간 상담 지원 `/assist` — 신규 기능 제안 ★
- 기존 화면들이 "끝난 통화"를 다루는 데 비해, 진행 중인 통화를 돕는 쪽으로 직접 제안·구현한 기능
- 진행 중 대화 → 마지막 고객 발화로 규정 RAG 검색 → 근거 기반 다음 응대 멘트 2안
  (원클릭 복사) + 에스컬레이션 주의 — STT·NLP·RAG·LLM 결합 지점

## 분석에서 운영 행동까지 — API 키 없이 동작하는 결정적 층
"이 통화는 해지 문의이고 감정은 강성"까지는 분류다. 콜센터의 다음 질문은
"그래서 누가 오늘 무엇을 하느냐"이고, 아래는 그 답을 규칙 계산으로 낸다.
LLM이 붙으면 판단이 더 정교해지지만, 없어도 기능 자체가 사라지지 않는다.

- **이탈 위험 지수**: 해지 의사·타사 비교·위약금 확인·반복 장애·법적 언급·보상 요구·
  신뢰 상실을 가중치로 세고 해결·유지 의사는 감점. **고객 발화만** 훑고 근거 발화를 함께 반환.
  LLM 점수가 있으면 규칙 신호가 만든 구간으로 보정(신호가 많을수록 구간을 좁힘).
- **에스컬레이션 티켓 초안**: 법무·리텐션·요금정산·네트워크·설치·보상 심의로 라우팅하고
  우선순위(P1~P3)와 SLA를 붙여 인수인계 문서로 조립. 근거 발화를 인용해 담당자가
  원문을 다시 듣지 않아도 판단할 수 있게 한다.
- **대화 지표**: 발화 비율·연속 발화·확인 질문·공감 표현·말 끊기 정황. 화자 라벨이
  없으면 null을 반환한다 — 계산할 수 없는 것을 0으로 보여주지 않는다.
- **통화 중 스크립트 가이드** (`/api/cc/guide`): 진행 중 대화에서 현재 단계를 판정하고
  빠뜨린 필수 멘트를 그대로 읽을 수 있는 문장으로 제시. 위험 신호에는 경보만이 아니라
  무슨 말을 해야 하는지까지 준다. **LLM을 호출하지 않는 유일한 엔드포인트** —
  통화 중에 쓰려면 즉시 답해야 하고, 규칙으로 답할 수 있는 질문에 LLM은 낭비다.
- **VOC 이상 감지**: 카테고리·원인 단위 급증과 강성·에스컬레이션·재문의 비율 경보.
  표본이 작을 때 비율만 보면 매일 경보가 뜨므로 최소 건수 조건을 함께 건다.
- **QA 코칭 이력**: 통화 한 건의 점수가 아니라 "반복해서 놓치는 것"을 집계.
  4건 미만이면 추세를 말하지 않는다 — 2건으로 "하락 추세"는 분석이 아니라 노이즈다.

## 결정적 검증층 — 지시가 아니라 검증
LLM이 자유 생성하는 지점마다 규칙 기반 검증을 붙인다.
- **원문 보존 게이트**(화자 분리): 라벨 제거 후 CER 15% 초과면 분리 결과를 버리고 원문 유지.
  전체 DP 대신 접두·접미 절단 + 밴드 폭 DP로 계산해 엣지 CPU 한도 안에서 끝낸다.
  계산 예산을 넘겨 검증할 수 없으면 통과시키지 않는다.
- **근거율**(RAG 답변·통화 요약): 문자 2-gram 오버랩 비율을 측정해 화면에 그대로 공개.
- **숫자 검증**(VOC 리포트): 리포트의 모든 숫자를 집계·파생 퍼센트 허용 집합과 대조.
- **일관성 밴드**(Auto QA): 규칙 신호로 만든 기대 구간을 벗어난 LLM 점수를 경계로 보정,
  보정 사실을 표시. 데모·폴백 점수는 "추정"으로 구분 표시.
- **응답 계약**(전 LLM 호출): ensureContract로 필수 필드·배열 요소 타입 검증.

## 안전장치
레이트리밋(IP·전체·일일 캡, 좁은 제한부터 검사) · 타임아웃+재시도+우아한 강등 ·
토큰·비용 실측 표시 · 텔레메트리(입력·IP 미저장) · 레이트리밋 버킷은 IP 해시(날짜별 회전,
최대 24시간) · Turnstile(무설정 시 fail-open) · 보안 응답 헤더(CSP·nosniff·X-Frame-Options·
Referrer-Policy·Permissions-Policy) · 배포 스모크 8종 · 전 데이터 가상
시나리오("한빛텔레콤") · 음성 미보관

## 편의 기능
VOC 통화 원장 CSV 내보내기(엑셀 한글 BOM) · 파이프라인 6단계 결과를 인수인계 문서 한 장으로
복사 · QA 체크리스트·도메인 사전·내 문서 커스텀 설정 브라우저 영속화(서버 미저장)
