# 콜센터 AX 워크벤치 — 전체 구현 기능 정리

**라이브**: https://callcenter-ax.pages.dev · **코드**: https://github.com/k95691368-ship-it/callcenter-ax
㈜포오스 "인공지능 융합" 파트(신입) 지원용 포트폴리오. 공고 담당업무 — *"STT, LLM, NLP, RAG
기술을 활용한 콜센터 AI 서비스: 분류, 요약, 검색, VOC·의도 분석 및 상담 품질 평가
자동화(Auto QA)"* — 를 동작하는 화면으로 1:1 구현했다.

## 원클릭 파이프라인 `/pipeline`
버튼 하나로 실제 프로덕션 API 6단계가 연속 실행된다:
**내장 음성 → ① Whisper STT → ② 도메인 용어 보정(튜닝 1단계) → ③ 화자 분리(NLP) →
④ LLM 통화 분석 → ⑤ Auto QA → ⑥ VOC 누적**. 시연용 가짜 경로 없음.

## 1. 녹취 전사 `/stt` — 오픈소스 Whisper STT
- **Whisper large-v3-turbo**(Workers AI)로 한국어 전사 — API 키 없이 라이브
- 입력 3종: 내장 샘플 원클릭 / **브라우저 마이크 녹음**(MediaRecorder) / 파일 업로드(≤6MB)
- **CER(문자 오류율) 측정**: 정답 스크립트 대비 Levenshtein 기반 정량 평가
- **Whisper 2종 모델 비교**: turbo vs base를 같은 음성으로 전사해 CER·지연 비교표
  (실측: turbo "한비텔레콤" 1자 오차 vs base "한 밑에 내 콤" 붕괴)
- **도메인 용어 보정(튜닝 1단계)**: 콜센터 용어 사전 후보정 + 보정 전/후 CER 개선 폭 표시
- **화자 분리**: 통짜 전사를 LLM이 상담사:/고객: 태깅 (원문 단어 보존) → QA 정확도 연결
- 텍스트 직접 입력 모드, 분석으로 보내기 연결. 업로드 음성 미보관

## 2. 통화 분석 `/analyze` — LLM 분류·요약·의도
- 유형 분류(가입/해지/요금/불만/기타) · 3줄 요약 · 감정(긍정~강성)+근거 · 의도 키워드 ·
  후속 조치 제안
- **에스컬레이션 원칙**: 법적 클레임·강성 민원·보상 요구는 AI가 결론 내리지 않고 담당자에게
  올림 — "반복은 대체하고 판단은 남긴다"
- 분석할 때마다 VOC 대시보드에 실시간 누적(localStorage, 서버 미전송)

## 3. 상담 품질 평가 `/qa` — Auto QA 이중 구조 100점
- **1층 규칙(결정적, 40점)**: 필수 멘트 5종 체크리스트 + 금지 표현 스캐너(위치 발췌·감점)
  — 화자 구분 시 상담사 발화만 평가. 키 없이도 실제 동작
- **2층 LLM(60점)**: 공감·명확성·해결력 각 20점 + 근거 코멘트 + 코칭 한 줄
- 순수 함수 점수 계산(테스트 완비), SVG 게이지 + A~D 등급

## 4. VOC 대시보드 `/voc`
- 내장 10건 + 직접 분석 건 합산: 유형 막대·감정 램프·일별 추이(경량 SVG)
- 통계 타일, 에스컬레이션 대기 목록, 통화 원장 테이블
- **AI 인사이트 리포트**: 집계 수치만 LLM에 전달(원문 미전송) → 핵심 발견·권고 액션 생성

## 5. RAG 지식 검색 `/search`
- 질문을 **bge-m3 임베딩** → 코사인 유사도 → 근거 문단만 사용해 답변(인용 id 표시)
- **내 문서 실시간 인덱싱**: 사용자가 규정을 붙여넣으면(최대 5건) 즉시 임베딩되어 내장
  8건과 같은 코퍼스에서 검색 — 서버 미저장, "내 문서" 배지
- 폴백: 임베딩 불가 시 키워드 랭킹 → LLM 불가 시 발췌 답변

## 6. 제작기 `/about`
공고 담당업무 ↔ 구현 1:1 매핑표 · 시스템 구조도 · **라이브/데모 정직 구분표**

## AI 엔진 — 3단 사다리
```
Claude Opus 5 (키 등록 시) → 오픈소스 Llama 3.3 70B (즉시 라이브) → 규칙 기반 데모
```
STT(Whisper)·임베딩(bge-m3)·LLM(Llama)까지 오픈소스 전 스택 대응, 엔진 출처 배지 표시.
