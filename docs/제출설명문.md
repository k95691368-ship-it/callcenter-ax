# 포트폴리오 설명문 (지원서 제출용, 약 520자)

㈜포오스 "인공지능 융합" 파트(신입) 지원 — 잡코리아 GI_Read/49580595

---

채용공고의 담당업무 한 문장 — "STT, LLM, NLP, RAG 기술을 활용한 콜센터 AI 서비스" — 를
실제로 동작하는 서비스로 만들어 제출합니다. (https://callcenter-ax.pages.dev)

녹취 전사(Whisper·CER 성능 평가·도메인 사전 튜닝), 분류·요약·의도 분석, 상담 품질 자동
평가(Auto QA), VOC 대시보드, 하이브리드 RAG 검색까지 공고의 다섯 업무를 화면 그대로
구현했고, 버튼 하나로 6단계 파이프라인이 실제 API로 연속 실행됩니다.

만들며 지킨 원칙은 "지시가 아니라 검증이 신뢰를 만든다"입니다. LLM이 자유 생성하는 모든
지점에 원문 보존 게이트, 근거율 측정, 숫자 검증 같은 결정적 검증층을 붙였고, 어떤 엔진이
답했는지, 무엇이 라이브이고 무엇이 데모인지, 비용과 실패 횟수까지 화면에 그대로
공개합니다. 테스트 128개와 37회의 배포 후 개선 기록이 이 과정의 증거입니다.

이틀간 기획부터 배포·운영까지 완주하며 확신이 생겼습니다. 포오스의 녹취 파이프라인
위에서 이 일을 계속 배우고 싶습니다. 배우는 속도로 보답하겠습니다.
