구현했고, 버튼 하나로 6단계 파이프라인이 실제 API로 연속 실행됩니다.

지점에 원문 보존 게이트, 근거율 측정, 숫자 검증 같은 결정적 검증층을 붙였고, 어떤 엔진이
답했는지, 무엇이 라이브이고 무엇이 데모인지, 비용과 실패 횟수까지 화면에 그대로
공개합니다. 테스트 832개와 40회 넘는 배포 후 개선 기록이 이 과정의 증거입니다.

# 기술 버전 (기술 구현 중심, 548자 공백 포함 / 433자 공백 제외)

콜센터 상담을 전사·분석·평가하는 AX 워크벤치입니다. 핵심은 LLM에 '지시'하는 대신 출력을 '검증'하는 결정적 검증층입니다.

화자 분리는 원문 보존 게이트로 CER 15% 초과 변형을 거부하고, RAG 답변과 요약은 2-gram 오버랩으로 근거율을 재며, VOC 리포트 숫자는 허용 집합 대조로 환각을 걸러내고, QA 점수는 규칙 신호 기반 일관성 밴드로 보정합니다.

검색은 bge-m3 임베딩 Vectorize 인덱스와 키워드 랭킹을 RRF(k=60)로 융합한 하이브리드 RAG입니다. 서빙은 Claude Opus 5 실패 시 Llama 3.3 70B, 규칙 데모로 잇는 3단 폴백과 일일 예산 상한을 두었고, 프롬프트 캐싱(입력 토큰 75% 절감 실측)과 통화 5건 1회 호출 일괄 분석으로 비용을 낮췄습니다. Whisper 2종 STT는 CER 정량 평가와 도메인 사전 후보정을 거칩니다.

개인정보 미저장 텔레메트리로 엔진 분포·폴백까지 공개하며, vitest 832개·스모크 8종 위에서 이틀간 40회 넘게 배포했습니다. (callcenter-ax.pages.dev)
